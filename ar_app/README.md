# ar_app

Files for the AR app.

To add files on the web: open this folder, then **Add file → Upload files**, drag them in and click **Commit changes** (25 MB per file in the browser).

Note: this repo is published as a public site (ar.verticecriativo.pt), so anything in here is publicly reachable at
`https://ar.verticecriativo.pt/ar_app/<file>`. Do not put private files here.
